Computation Gallery
===================

This section contains a collection of constructed logical computations and their simulation results.

The examples in this gallery are now provided as Python example scripts and
rendered using sphinx-gallery. The generated examples will appear under the
``auto_examples`` section of the HTML output. The source example scripts are
located in ``docs/gallery/examples/``. Example filenames:

.. list-table:: Examples
    :widths: 20 80

    * - memory
       - docs/gallery/examples/example_memory.py
    * - cnot
       - docs/gallery/examples/example_cnot.py
    * - move_rotation
       - docs/gallery/examples/example_move_rotation.py
    * - three_cnots
       - docs/gallery/examples/example_three_cnots.py
    * - steane_encoding
       - docs/gallery/examples/example_steane_encoding.py
